# RPG 卡帶設計手冊(給做遊戲的人)

這台遊戲機已經會:走路、講話、接任務、打怪、升等、撿東西、存檔。
你要做的是**一張卡帶**:畫地圖、寫劇情、放人物、設計任務、決定怪物有多強。全部是填表,不用寫程式。

## 一、卡帶長什麼樣

```
games/<卡帶名>/
  game.json        標題、簡介、起點、主角初始數值、升等設定、結局
  tiles.json       每種地面長什麼樣(顏色、種類)
  dialogues.json   所有對話
  quests.json      所有任務
  items.json       所有道具
  enemies.json     所有怪物
  encounters.json  遭遇表(哪裡會遇到什麼怪、機率多少)
  maps/*.json      地圖(用 Tiled 畫)
```

最快的起手:**複製 `games/demo` 整個資料夾改名**,然後一個檔一個檔改。
玩的時候網址加 `?game=<卡帶名>`。

## 二、怎麼檢查有沒有填錯

兩個方法,訊息一模一樣、都是白話中文:

- 直接開遊戲:填錯的話開場畫面會列出來,例如「任務 q2 的獎勵道具 potion_x 不在 items.json」。
- 或在電腦上跑 `node scripts/validate-game.mjs games/<卡帶名>`。

錯誤一定要修到 0;「提醒」不擋(例如某個道具沒地方拿得到),看看是不是你忘了放。

**JSON 三個常見錯**:少逗號、多逗號(最後一筆後面不能有逗號)、引號用成中文的「」。整份貼到 jsonlint.com 會告訴你第幾行。

## 三、game.json

```json
{
  "id": "demo",                         英數,會變成網址與存檔的名字
  "title": "晨光村的勇者",
  "subtitle": "一句副標",
  "intro": "開場簡介,可以換行",
  "howto": ["使用說明一條一條"],
  "maps": { "village": { "file": "maps/village.json", "name": "晨光村" } },
  "start": { "map": "village", "x": 4, "y": 6, "dir": "right" },      起點(格子座標從 0 數)
  "defeat": { "map": "village", "x": 3, "y": 3, "goldLossRate": 0.1, "text": "倒下後看到的字" },
  "hero": {
    "name": "勇者", "level": 1,
    "hp": 30, "mp": 8, "atk": 7, "def": 3, "spd": 5, "gold": 20,
    "items": { "potion": 2 },                                           起始道具
    "look": { "color": "#3f7fd6", "hair": "#4a3020", "skin": "#f6d3b3" },   衣服、頭髮、皮膚顏色
    "skills": [ { "id": "smash", "name": "重擊", "mp": 3, "mult": 1.8, "desc": "說明" } ]
  },
  "levels": { "base": 10, "max": 20, "growth": { "hp": 6, "mp": 2, "atk": 2, "def": 1, "spd": 1 } },
  "encounterCooldown": 3,               打完一場後幾步內不會再遇敵
  "ending": { "title": "結局標題", "text": "結局文字" }
}
```

升下一級要的經驗值 = `base × 等級^1.5`(base 10:10、28、52、80、112…)。每升一級加 growth 的數值。

## 四、數值怎麼算(調怪物強度用)

- 傷害 = (攻擊 × 技能倍率 − 防禦 × 0.5)× 0.85~1.15,最少 1;8% 會心一擊 ×1.5
- 每回合你先出手,再換每一隻活著的怪打你
- 逃跑成功率 = 50% +(你的速度 − 最快的怪的速度)%,最低 20%、最高 90%;`fixed` 的戰鬥逃不掉
- 體力歸零不會 Game Over:回到 `defeat` 設的地方、體力全滿、金幣扣 `goldLossRate`

經驗:主角 Lv1 攻 7 打防 1 的怪 ≈ 6 點。怪的 hp 設成「幾下打死」× 6 就差不多。

## 五、地圖(Tiled)

用免費的 [Tiled](https://www.mapeditor.org/) 開 `maps/*.json`。規矩:

| 項目 | 規矩 |
|---|---|
| 圖塊圖層名字 | `ground`(地面,一定要)/ `deco`(畫在地面上的樹、花、床…)/ `collision`(有東西的格子不能走) |
| 物件圖層 | 隨便取名;每個物件的 **Type(或 Class)** 決定它是什麼(下表) |
| 匯出 | Tile Layer Format 選 **CSV**;圖塊集要 **Embed**(嵌進地圖)|
| 地圖名字 | 寫在 game.json 的 maps 裡(`name`) |

物件種類與自訂屬性(Custom Properties):

| Type | 屬性 | 說明 |
|---|---|---|
| `npc` | `dialogue`(必要)、`name`、`color`、`hair`、`face`(up/down/left/right)、`shape`(用怪物外型:blob/wolf/skeleton/spider/bat/ghost) | 會講話的人;站著不動、不能穿過 |
| `portal` | `map`、`x`、`y`、`dir` | 走到這格就傳送 |
| `item` | `item`、`qty` | 地上的道具,走過去自動撿,撿過就不再出現 |
| `zone` | `encounter` | 用矩形畫一塊遇敵區,走在裡面每一步都有機率遇敵 |
| `heal` | (無) | 休息點(床):面對它按確認 ⇒ 體力魔力全滿並存檔 |
| 任何物件 | `showIf` / `hideIf` | 條件(見第八節),例如巨蛛 `hideIf = flag:boss_down` 打倒後就消失 |

### 圖塊長什麼樣:圖片圖塊集(建議)或 tiles.json(程式畫)

**用圖片圖塊集**(示範卡帶 v3 起就是這樣,美術是 Kenney 的 Tiny Town / Tiny Dungeon,CC0):

| 步驟 | 做法 |
|---|---|
| 1 PNG 放哪 | `games/<卡帶>/assets/` 底下,用「無間距」的整張圖(Kenney 包裡的 `tilemap_packed.png`),一格 16×16(或你卡帶統一的尺寸;地圖的 tilewidth 要跟它一樣) |
| 2 Tiled 新增圖塊集 | New Tileset → Based on Tileset Image → 選那張 PNG、Tile width/height 填格子大小、Margin 0、Spacing 0;**勾 Embed in map**(嵌進地圖;外部 .tsx 引擎不吃) |
| 3 image 路徑 | Tiled 會寫成**相對於地圖檔**的路徑;地圖在 `maps/`、圖在 `assets/` 就是 `../assets/xxx.png`,引擎會自己換算(反斜線也可以) |
| 4 幾個圖塊集都行 | 一張地圖可以同時嵌多個圖塊集(例如村子用 Tiny Town、家具用 Tiny Dungeon),`firstgid` Tiled 會自己接續 |
| 5 沒圖的格子才寫 tiles.json | 圖片圖塊集涵蓋到的 gid **不用**寫進 `tiles.json`;只有圖裡都沒有、要用程式畫的(例如示範卡帶的床)才列,鍵 = 那個 gid |
| 6 缺的圖自己補一張小的 | 兩包都沒有的地形(示範卡帶的池塘)就自己畫一張小 PNG 當第三個圖塊集(`assets/water.png` 48×48 = 3×3 九宮格,照 Kenney 配色),一樣 Embed 進地圖 |

引擎畫圖時:這個 gid 有圖就畫圖;沒圖就查 `tiles.json`;兩邊都沒有 ⇒ 驗證器會擋(開場畫面列出哪張地圖哪一號)。
縮放是整數倍、關掉平滑,像素圖不會糊;每格在畫面上至少 44、最多 112 css 像素,16px 與 32px 的圖塊集都可以用。

**用 tiles.json 程式畫**(沒有美術時的佔位):`{"1": {"name":"草地","color":"#5a9e4b","kind":"grass"}}`。
kind 可用:`flat grass tallgrass water tree wall roof floor path rock cavefloor cavewall bed door cave flower fence table`。

示範卡帶三張圖用到的格號(格號從 0 數;gid = 圖塊集 firstgid + 格號;Tiny Town firstgid=1、Tiny Dungeon 133、水 265、程式畫的 274)請看 `scripts/make-demo-maps.mjs` 最上面的對照表。

## 六、對話(dialogues.json)

一個對話 id = 一串句子。每句是一個 `{ }`,可以同時做好幾件事。

| 寫法 | 意思 |
|---|---|
| `{ "speaker": "村長", "text": "你好!" }` | 講一句。speaker 省略就沿用上一句的 |
| `{ "text": "要幫忙嗎?", "choices": [ {"label":"好","next":"d_yes"}, {"label":"不","next":"d_no"} ] }` | 選項,選了就跳到另一個對話 |
| `{ "if": "quest:q1=done", "then": "d_after", "else": "d_before" }` | 條件跳轉;else 可省略(不成立就繼續下一句) |
| `{ "set": { "flag": "met_elder" } }` | 設一個旗標(記住發生過的事) |
| `{ "quest": "q1", "action": "start" }` | 接任務 |
| `{ "quest": "q1", "action": "complete" }` | 完成任務、發獎勵(目標沒達成會跳過,所以前面要先用 if 判 ready) |
| `{ "give": { "item": "potion", "qty": 1 } }` | 給道具 |
| `{ "gold": 20 }` | 給金幣(負數=扣) |
| `{ "battle": "boss_spider" }` | 打一場(用遭遇表 id);沒打贏對話就結束 |
| `{ "heal": true }` | 體力魔力全滿 |
| `{ "ending": true }` | 進結局畫面 |
| `{ "end": true }` | 對話提早結束 |

文字裡可以用:`{hero}` 主角名、`{gold}` 金幣、`{progress:q1}` 任務進度(例如「綠團子 2/3」)。

**典型的 NPC 寫法**(先用 if 把狀態分流,最後才是第一次見面的台詞):

```json
"elder": [
  { "if": "quest:q1=done",  "then": "elder_thanks" },
  { "if": "quest:q1=ready", "then": "elder_turnin" },
  { "if": "quest:q1=active","then": "elder_wait" },
  { "speaker": "村長", "text": "第一次見面的台詞" },
  { "text": "要幫忙嗎?", "choices": [ {"label":"好","next":"elder_yes"}, {"label":"不","next":"elder_no"} ] }
]
```

## 七、任務(quests.json)

```json
"q_slime": {
  "title": "清除綠團子", "desc": "幫村長打倒 3 隻綠團子。",
  "objective": { "type": "kill", "enemy": "blob", "count": 3 },
  "reward": { "xp": 15, "gold": 30, "items": { "potion": 1 } }
}
```

目標三種:`kill`(打倒 N 隻,從接任務那一刻起算)、`collect`(背包裡有 N 個某道具,完成時交出去;不想交出去加 `"consume": false`)、`flag`(某旗標被設)。
狀態:`inactive` 沒接 → `active` 進行中 → `ready` 目標達成(可以回報)→ `done` 完成。
任務要有一句對話 `start` 它,玩家才接得到(驗證器會提醒)。

## 八、條件怎麼寫(對話的 if、物件的 showIf / hideIf 都一樣)

| 寫法 | 意思 |
|---|---|
| `flag:boss_down` / `!flag:boss_down` | 旗標有 / 沒有 |
| `quest:q1=active` | 任務狀態(可列多個:`quest:q1=active,done`;ready 也算 active) |
| `quest:q1=ready` | 目標達成還沒回報 |
| `item:herb>=2` | 背包至少 2 個(省略 `>=` 就是至少 1 個) |
| `level>=5` | 等級至少 5 |

## 九、道具、怪物、遭遇表

```json
"potion": { "name": "藥水", "type": "heal", "hp": 20, "desc": "回復 20 點體力" }
```
type:`heal`(hp / mp 回復量)、`material`(材料,任務用)、`key`(關鍵物品)。

```json
"blob": { "name": "綠團子", "hp": 12, "atk": 4, "def": 1, "spd": 3, "xp": 7, "gold": 4,
          "drops": [ { "item": "potion", "chance": 0.1 } ],
          "sprite": { "shape": "blob", "color": "#6cc24a" }, "boss": false }
```
shape:`blob wolf skeleton spider bat ghost`。boss 只是標記(頭目戰要用 fixed 遭遇表才逃不掉)。

```json
"field": { "rate": 0.12, "groups": [ { "enemies": ["blob"], "weight": 5 }, { "enemies": ["wolf"], "weight": 2 } ] },
"boss_spider": { "fixed": ["spider"] }
```
rate = 每走一步遇敵的機率;groups 依 weight 抽一組(一組最多 4 隻畫面才擠得下)。

## 十、測試你的卡帶

- 網址加 `&seed=7`:亂數固定,每次遇到的怪一樣,方便重現。
- 網址加 `&debug=1`:瀏覽器主控台可以用 `__rpg.debug.setLevel(7)`、`__rpg.debug.give('potion', 5)`、`__rpg.teleport('cave', 12, 4, 'up')`。
- 想讓別人玩:交給爸爸部署,拿到連結就能分享。

## 十一、遊戲機做不到的事

即時動作戰鬥、商店、裝備、隊伍、狀態異常、音樂音效、雲端存檔(v1 都沒有)。
想要的話開一張卡片講清楚「玩家會看到什麼」,做進遊戲機之後所有卡帶都能用。
